# Checkpoint gantries

Original replacement artwork inspired by the retail game's blue overhead
checkpoint signs, red vertical MIDTOWN panels and yellow open truss towers.
No pixels or meshes are extracted from the reference screenshots or retail data.

The metalwork is generated in `src/checkpoint_gate.rs`: four merged meshes per
gate, PBR metal materials, double-sided readable signs and a separate green
FINISH variant. Posts sit outside the trigger radius; the authored heading
orients the gantry using the existing inferred heading convention. Dimensions
and finish artwork are designed, not claims about original game rules.

The PNG signs are generated by `generate.py` with Pillow and Arial Bold
(macOS system font; change the font path for other platforms). Runtime loading
uses embedded PNGs, so no Python or installed font is required to play.
