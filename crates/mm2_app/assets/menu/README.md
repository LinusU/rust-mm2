# Menu artwork

`city-night.png` is original artwork generated with the built-in imagegen tool
for this project. It is embedded into the executable so menus work regardless
of the launch directory. The reference screenshots informed the palette and
arcade mood; no retail menu images are included.

Generation prompt:

> Use case: stylized-concept. Asset type: original background artwork for a driving game's graphical menu. Create a wide 16:9 cinematic late-1990s arcade racing illustration: a fictional silver sports coupe seen from rear three-quarter on the right, San Francisco-inspired steep streets and suspension bridge silhouettes, layered architectural collage. Deep midnight indigo and electric cobalt on the left transitioning to blazing amber and burnt orange on the upper right, midnight blue across the bottom. Glossy airbrushed painted promotional art with subtle motion streaks, high craft. Left half intentionally subdued with space for UI overlays. No text, no logos, no badges, no UI controls, no watermark. Original composition, no reproduction of any existing game artwork.

Panels, button borders, focus indicators and loading decoration are generated
by Bevy UI. The showroom imports vehicle meshes and textures from the user's
installation through the same renderer used during driving.

`london-night.png` is a second original image generated with the same built-in
tool for the London destination card. Prompt:

> Use case: stylized-concept. Asset type: original city selection postcard for an arcade driving game. Wide landscape 16:9 cinematic London-inspired streets at blue hour: recognizable Westminster clock tower silhouette, stone riverside architecture, wet pavement, sweeping amber light trails, suspension and masonry bridge forms. Painted late-1990s arcade promotional art, glossy airbrushed richness, deep cobalt blue shadows and orange lit skyline. No cars in foreground, no text, no logos, no interface, no watermark. Original illustration.
