# Feature specifications

`Fxx-*.md` are the feature specs the project's tasks are written against:
each task names its feature and the acceptance-criterion IDs (`Fxx-ACnn`)
it advances. `PROJECT.md`, `ARCHITECTURE.md`, `QUALITY-GATES.md` and
`SOURCES.md` are the shared contract the specs tell you to read alongside.

They came from the planning pack the project was first driven with (the
Ralph loop) and are now owner-maintained: agents may not change them.
Where a spec and the code disagree, the code and the retail data are the
evidence; record the disagreement on the task rather than editing the spec.
