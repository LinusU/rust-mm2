# Last iteration — the reset leg of F25-C on an impaired link (iteration 9 of the new run)

Selection: iteration 8's commit (`29647cb`) passed gates and review with no blocking findings, and report 7 items 1–11 are all implemented candidates, so nothing was pending repair. Picked the first open leg the reviewer and iteration 8 both named that was small and ready: the process-level reset on an impaired link. Writing it exposed a real gap: the scheduled `--reset-at` ask was a one-shot, so a lossy link that ate that one frame left the run waiting for a reset that was never asked for.

Change: `netdrive::DevResetAsk` (pure rule) + `DEV_RESET_RETRY` (3 s wall clock, above the 1 s `RESET_REQUEST_COOLDOWN`): `send_dev_reset_request` asks at the tick and again every 3 s until an own-seat epoch reset has been applied. New `NetDriveReport::own_resets` (subset of `resets`, bumped in the own-seat `authority_reset` branch only; not printed, so no record changes). Wall clock because a headless client runs ticks much faster than the wire answers; a tick-based retry would fire inside the round trip and be dropped by the host cooldown. The downlink needs no retry: the epoch is per-seat state on every `Snap`.

Tests: `netdrive::tests::the_scheduled_reset_ask_repeats_until_the_own_seat_resets` (deterministic rule); `net_drive::a_scheduled_reset_comes_back_across_two_processes_on_an_impaired_link` (host + alice `--reset-at 1200 --until-resets 1` + bob through an `ImpairProxy` armed both ways after `Start`: 40 ms delay, 30 ms jitter, 30 % loss, 10 % dup, 10 % reorder; asserts the proxy carried and impaired both directions, alice asked ≥ 1 and her reset came back, travelled > 50 m then `moved<5 m`, host granted ≥ 1). The clean leg was refactored onto the shared `run_reset_pair` helper with its exact assertions unchanged (1 ask, 1 granted, 0 dropped). 4/4 consecutive passes of the impaired leg; in one run alice asked 3 times (two asks lost on the wire) and the retry carried it — the count is a floor, because a single run cannot force the loss. Bob runs his frame budget in the impaired leg, not `--until-peer-left`: through a lossy relay alice's one-shot `Leave` can be dropped and the relay keeps her socket open, so bob would never see her go (first attempt hung on exactly that).

Gates (foreground): `cargo fmt --all -- --check` pass; `cargo clippy --locked --workspace --all-targets --all-features -- -D warnings` pass; `cargo test --locked --workspace` exit 0 (2946 passed, 0 failed). Both reset process tests passed 4/4 in isolation before the full run.
